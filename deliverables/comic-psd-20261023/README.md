# 漫画宽带海报分层 PSD

原图尺寸：1776 × 2368；51 个栅格图层；用户提供的 PNG 保持不变。

## 编辑方式
使用 Photoshop 或 Photopea 打开 output.psd。各图层保持原位，可移动、隐藏、缩放或替换。图层自下向上组织为背景、漫画场景、人物场景、主标题、品牌、气泡、价格、1000M 宽带、区域标签、五张权益卡片和咨询按钮。
文字和图标是栅格图层，不是原生可改字的文字对象或矢量对象。需要改字时隐藏对应文字层，使用文字工具重新输入。

## 拆层边界
这是从一张平面 PNG 近似拆出的区域/元素图层，不是原设计工程。
漫画四个分镜各为一个场景图层；人物、手机和沙发为中央场景区域，不声称逐根头发或每件物体均已独立抠出。前景猫咪另有区域蒙版。
原图文字、标识和画面区域保留源像素。对话框文字、价格、权益卡片图标及文字、按钮文字已另拆。

## 遮挡和背景
最底层是 AI 生成的空白漫画风背景，不代表原始隐藏内容。
第二层“原背景保真覆盖”仅保留未抽出区域，用于保持默认合成与原图相同。大幅改变布局时可隐藏该层以使用完整补绘背景；两者视觉可能不同。
父底板中被文字/前景遮挡的区域通过邻近颜色近似填补。漫画人物或复杂场景中的真实遮挡内容无法从平面图恢复。移动场景、文字或人物后，局部可能需要修补蒙版或重绘背景。

## 验证
验证结果见 diagnostics/validation.json：检查 PSD 读取、各帧读取、图层 PNG ZIP 完整性以及默认合成与原图像素比较。
未在 Photoshop 图形界面中打开验证，不能承诺所有第三方编辑器行为完全相同。

## 文件
output.psd：主交付。
output.preview.png：默认合成预览。
psd_full_canvas_layers.zip：独立透明 PNG 图层包，每张均为原图全画布尺寸，放置于 (0,0)。
manifest.json：图层名称、顺序与来源。
