# 拼贴海报分层 PSD

原图尺寸：1776 × 2368；共 51 个栅格图层。默认合成保留原图效果，层名以编辑用途命名。

## 使用
用 Photoshop 或 Photopea 打开 collage_broadband.psd，可移动、隐藏、缩放、替换图层。文字、图标和人物均为栅格图层，不是可直接改字的原生文字或矢量对象。
主标题、59、单位贴纸、1000M、高速宽带、装饰、人物场景、电脑、游戏设备、猫咪、摄像头、权益卡片和咨询按钮已按区域拆分。人物和沙发作为场景区域，没有逐发丝或逐件衣物分离。

## 背景与遮挡
01 是 AI 补绘背景，不代表原始隐藏内容；02 是保留原始可见背景的保真覆盖层。大幅移动版面时可隐藏 02，使用完整补绘背景，但布局和细节可能不同。
父底板在被文字、物体或上层覆盖的位置使用邻近颜色近似填补；不能从平面图片还原真正的隐藏画面。复杂边缘、画面纹理或阴影可能随区域保留，移动后可能需要细修蒙版。
独立字层保留原图的刷笔风格；磨损碎点、字周的纹理并不等于完全透明的字体轮廓。
