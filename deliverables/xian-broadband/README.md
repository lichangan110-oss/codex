# 西安移动宽带海报拆层说明

原图：1792 × 2144 PNG。使用 bggg-creator-image2psd 导出 31 个可移动栅格图层。

## 图层和使用
- 01：AI 补绘的完整客厅背景，用于被遮挡区域的近似恢复，内容不是原始隐藏像素。
- 02：原背景保真覆盖，包含原始可见背景，以保持全部图层开启时与原图一致。若大幅移动布局而出现原背景与补绘区域接缝，可隐藏该层，使用 01 的完整补绘背景。
- 03–11：品牌、顶部文案、主副标题、右上标语、59 价格和单位。
- 12–13：绿色笔刷及独立的宽带白色文字。
- 14–18：权益栏底板与四组图标文字，每组可独立移动。
- 19–22：赠品底板、礼盒、送字圆章、赠品文字。
- 23–24：光猫和四天线路由器，使用手工区域蒙版保留原图位置。
- 25–29：底部信息底板及四组权益。
- 30–31：咨询按钮底板及其文字图标。

## 限制
- 文字均为栅格层，不是 Photoshop 原生可编辑文字；可移动/隐藏/替换，不能直接修改字符。
- 由单张平面图近似还原图层，设备边缘及文字边缘可能携带少量原背景像素。放到不同背景或大幅移动后可能需要细修蒙版。
- 层间遮挡处采用补绘/邻近颜色填充，无法恢复拍摄或设计时的真实隐藏内容。
- 原图中的室内植物、沙发、电视和桌面属于背景，没有分别拆成独立物体。
- 未在 Photoshop/Photopea 图形界面打开验证；验证限于 PSD 读取、图层及合成像素比较。

## 文件
output.psd：主文件。

manifest.json：底到顶的图层顺序和来源。
diagnostics/validation.json：本次验证结果。

生成背景使用 imagegen，未用重绘图替代源图中的文字或设备；原始图层像素来自 original_reference.png。
